## 📌 Deskripsi Proyek
Proyek ini merupakan karya landing page interaktif berbasis React & Vite yang mengintegrasikan seluruh informasi **Bidang Kemahasiswaan** (ORMAWA, UKM, Prestasi Mahasiswa, Layanan Mahasiswa) serta **Al-Islam & Kemuhammadiyahan (AIK)** (Kegiatan Keagamaan, Fiqh Siber, Syiar Digital, dan Nilai Kemuhammadiyahan) secara eksplisit dalam satu alur cerita visual yang harmonis.

## 🚀 Fitur & Keunggulan Utama
- **Theme Switcher Mode Terang & Gelap**: Animasi *Circular Reveal Transition (60 FPS)* berbasis View Transitions API (diinspirasi oleh arsitektur proyek DonasiTrust).
- **Hero Section Layout DonasiTrust**: Teks rata kiri yang bold dan bersih disandingkan dengan *3-column 3D vertical sliding marquee cards*.
- **Floating Interactive BubbleMenu**: Navigasi gelembung mengambang menggunakan GSAP dengan tombol Theme Toggle yang menyatu di samping menu burger.
- **ScrollExpand Showcase 3D**: Penjelajahan visual kampus siber yang membesar secara responsif mengikuti guliran tetikus (*scroll progress*).
- **Interactive Accordion Gallery**: Dokumentasi galeri aktivitas mahasiswa dan kegiatan AIK dengan efek ekspansi gambar interaktif.
- **100% Responsif & Bebas Error**: Teruji pada berbagai ukuran layar seluler dan desktop dengan audit `0 error` dari Oxlint.

- **Core Framework**: React 19 + Vite 8

## 💻 Cara Menjalankan Proyek Secara Lokal

### Prerequisites
- Node.js (v18.0.0 atau yang lebih baru)
- npm / yarn / pnpm

### Langkah Pemasangan & Menjalankan Dev Server
```bash
# 1. Clone repositori
git clone https://github.com/[username]/sibermu.git
cd sibermu

# 2. Install dependensi
npm install

# 3. Jalankan server pengembangan lokal
npm run dev

# Halaman web akan dapat diakses di http://localhost:5173
```

### Langkah Build untuk Produksi & Linting
```bash
# Uji linting kode
npm run lint

# Build bundel produksi
npm run build
```
